# TuneBoss Admin - Backend 

Backend API server untuk admin panel TuneBoss Marketplace, dibangun dengan Express.js.

## Tech Stack
- **Framework**: Express.js
- **Database**: PostgreSQL
- **ORM**: Drizzle ORM
- **Language**: TypeScript

## Scripts

- `npm run dev`: Menjalankan development server dengan watch (port 8001)
- `npm run build`: Mengompilasi TypeScript menjadi JavaScript
- `npm run start`: Menjalankan production server
- `npm run lint`: Menjalankan ESLint
- `npm run typecheck`: Memeriksa tipe TypeScript tanpa melakukan kompilasi
