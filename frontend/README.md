# TuneBoss Admin - Frontend

Aplikasi SPA frontend untuk admin panel TuneBoss Marketplace, dibangun menggunakan Next.js 16 (App Router).

## Tech Stack
- **Framework**: Next.js 16 (React 19)
- **Styling**: TailwindCSS 4
- **UI Components**: shadcn/ui, Radix UI, Base UI
- **Data Fetching**: TanStack Query
- **Typography**: Futura PT & SQR721BE

## Scripts

- `npm run dev`: Menjalankan development server (port 3000)
- `npm run build`: Membangun production bundle
- `npm run start`: Menjalankan production server
- `npm run lint`: Menjalankan ESLint (`eslint .`)
- `npm run doctor`: Menjalankan react-doctor untuk analisa project
- `npm run typecheck`: Memeriksa tipe TypeScript tanpa melakukan kompilasi
